# 📄 PDF-Chat-RAG

A Retrieval-Augmented Generation (RAG) app that lets you upload any PDF and ask questions about its content in plain English. It retrieves the most relevant sections of the document and uses an LLM to generate accurate, grounded answers — instead of relying on the model's general knowledge.

## Features
- Upload any PDF and ask questions about it
- Semantic search using sentence embeddings (not just keyword matching)
- Fast vector search with FAISS
- Answers generated by Groq's LLM API, grounded only in the document's content
- Simple, styled Streamlit web interface

## Tech Stack
- **Python**
- **LangChain** – text chunking
- **Sentence-Transformers** (`all-MiniLM-L6-v2`) – embeddings
- **FAISS** – vector similarity search
- **Groq API** (`openai/gpt-oss-20b`) – LLM for answer generation
- **Streamlit** – web UI

## How It Works
1. User uploads a PDF
2. Text is extracted and split into overlapping chunks
3. Each chunk is converted into an embedding vector
4. Vectors are stored in a FAISS index
5. User's question is embedded and matched against the closest chunks
6. Matched chunks + question are sent to the LLM, which generates an answer grounded in the retrieved context

## Setup

```bash
git clone https://github.com/your-username/PDF-Chat-RAG.git
cd PDF-Chat-RAG
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # Mac/Linux

pip install -r requirements.txt
```

Create a `.env` file in the project root:
GROQ_API_KEY=your_groq_api_key_here

## Run

```bash
streamlit run app.py
```
